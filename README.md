# Tea Explorers Club

A command-line tool for the Tea Explorers Club newsletter. It manages the
subscribers, reviews an issue, and sends practice copies to a test mail server.

## Requirements

- Python 3.12 or newer
- uv

## Setup

```bash
uv sync
```

## Run

```bash
uv run tea-explorers-club
```

## Test

```bash
uv run pytest
```
